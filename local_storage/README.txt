# Thư mục Lưu trữ Cục bộ (Local Computer Storage) - LexiSync IELTS

Thư mục này tự động lưu trữ vĩnh viễn toàn bộ các tệp tài liệu và âm thanh mà bạn đã tải lên trong ứng dụng:

- `audio/`: Chứa tất cả tệp Audio đề nghe IELTS (.mp3, .wav, .m4a) với tên gốc rõ ràng, có thể nghe bằng Windows Media Player, VLC, điện thoại...
- `pdfs/`: Chứa tất cả tệp đề thi PDF (.pdf) bản gốc trích xuất từ sách Cambridge, IDP hoặc BC, có thể mở bằng Acrobat Reader, Edge, Chrome...

Bạn có thể mở thư mục này bất kỳ lúc nào bằng cách bấm nút **"Tệp máy tính"** -> **"Mở trên Explorer"** ngay trên giao diện của ứng dụng.
